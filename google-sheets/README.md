# Ответы гостей в Google Таблицу

## 1. Таблица и скрипт

1. Откройте таблицу: https://docs.google.com/spreadsheets/d/1UipOS2N3X1w6IwIpsEtHBh-PIKG6fGoQdGEkTotmJMQ/edit
2. В меню: **Расширения → Apps Script**.
3. Удалите всё, что там написано, и вставьте содержимое файла `rsvp.gs`. Нажмите 💾 (Сохранить).

## 2. Опубликовать

1. Справа сверху: **Начать развёртывание → Новое развёртывание**.
2. Шестерёнка «Выберите тип» → **Веб-приложение**.
3. Заполните:
   - Описание: `RSVP`
   - Запуск от имени: **Я**
   - У кого есть доступ: **Все**
4. **Начать развёртывание** → Google попросит разрешения → выберите свой аккаунт →
   «Дополнительные настройки» → «Перейти на страницу …» → **Разрешить**.
   (Предупреждение появляется, потому что скрипт ваш и не проверен Google, — это нормально.)
5. Скопируйте **URL веб-приложения** — он заканчивается на `/exec`.

Проверка: откройте этот URL в браузере — должно появиться `{"ok":true,"message":"RSVP endpoint работает"}`.

## 3. Подключить к сайту

Ссылка уже вписана в `src/rsvp.ts` (`RSVP_ENDPOINT`) — сайт пишет в таблицу и локально, и после публикации,
настраивать хостинг не нужно. Если скрипт развернуть заново как **новое** развёртывание, ссылка поменяется —
её нужно заменить там же. (Новая *версия* того же развёртывания ссылку не меняет.)

Для тестов можно направить ответы в другую таблицу: файл `.env` с `VITE_RSVP_ENDPOINT=…/exec`.

## Что будет в таблице

Лист «Ответы» создастся сам при первом ответе:

| Дата | Имя | Ответ | Регистрация | Ужин |
|---|---|---|---|---|
| 24.10.2026 14:05 | Мария и Андрей | Регистрация и ужин | да | да |

- Если гость поменяет ответ, его строка обновится, новая не добавится.
- Сколько придёт: `=COUNTIF(D:D;"да")` — на регистрацию, `=COUNTIF(E:E;"да")` — на ужин.
- Если поменяете код скрипта — **Управление развёртываниями → ✏️ → Версия: новая → Развернуть** (URL останется тем же)..
